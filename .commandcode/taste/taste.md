# Taste

## Design & typography
- Prefers Georgia (serif) for prose/body/supporting text — descriptions, About copy — while display/heading typography stays as-is. Confidence: 0.5
- Prefers decorative/ambient visuals kept subtle so content reads first — asks for accent lines and background glows to be dialed back ("a little more dimmer", "the upper glow should be less bright. You choose too bright") rather than letting ornament compete with text, and expects effects to fade gradually rather than stop at a hard edge. Confidence: 0.6

## Workflow & UI expectations
- Expects every UI change to be carried through both light/dark themes and mobile breakpoints ("sync the changes for dark mode and mobile"), not left desktop-light-only. Confidence: 0.65

## Accessibility
- Expects accessibility to be treated as a first-class requirement in web work (contrast, focus handling, touch targets, ARIA semantics), not an afterthought — pushes back with "increase the website accessibility" rather than accepting a visually-finished but non-compliant result. Confidence: 0.55
